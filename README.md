# Impact-semences-certifiees-rendement-thies
Analyse de l'impact de l'utilisation des semences cerifiées sur le rendement agricolé de la région de thiès(sénégal), à l'aide d'un modéle lineaire a effets mixtes avec R.

## 📌 Présentation du projet

Ce projet analyse l’impact de l’utilisation des semences certifiées sur le rendement agricole dans la région de Thiès(Thiès, Mbour, Tivaouane), au Sénégal.

L’étude vise également à identifier les principaux facteurs associés au rendement agricole à l’aide de méthodes statistiques et d’un modèle linéaire à effets mixtes.

## 🎯 Objectifs

- Évaluer l’impact de l’utilisation des semences certifiées sur le rendement agricole.
- Identifier les principaux facteurs déterminants du rendement.
- Analyser les relations entre les caractéristiques agricoles, les pratiques culturales et le rendement.
- Produire des résultats statistiques permettant d’appuyer la prise de décision.

## 📊 Données

Les données utilisées portent sur plusieurs campagnes agricoles dans la région de Thiès et concernent notamment 699 observations effectués sur les variables suivantes :

- le rendement agricole ;
- l’utilisation de semences certifiées ;
- les quantités d’engrais utilisées ;
- les variétés de semences utilisées;
- les niveaux de semences produites;
- le type NPK;
- especes produites;
- faculté de germination;
- superficies;
- GIE;
- experience;
- la pluviométrie ;
- les caractéristiques des semences ;
- les superficies contrôlées ;
- les caractéristiques des producteurs et des zones de production.

## 🔬 Méthodologie

L’analyse comprend plusieurs étapes :

1. Nettoyage et préparation des données ;
2. Analyse descriptive et exploratoire ;
3. Visualisation des données ;
4. Sélection des variables pertinentes avec le RandomForest et le stepwise ;
5. Modélisation statistique ;
6. Estimation d’un modèle linéaire à effets mixtes ;
7. Interprétation des résultats.

## 📈 Résultats principaux

Les résultats mettent en évidence que l'utilisation de semences certifiées et adaptés est associée à une hausse de 59.6% du rendement agricole.

 L’utilisation de bonnes formules d'engrais telles que le 15-15-15 et le 10-10-20 entraine une hausse du rendement de 39% et 33% .

L’analyse permet également d’identifier plusieurs facteurs agronomiques et environnementaux associés aux variations du rendement.
